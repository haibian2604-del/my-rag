# 信息安全管理规定

## 账号与密码

所有内部系统密码必须每 90 天更换一次，密码长度不少于 12 位且包含大小写字母、数字与符号。禁止在不同系统间重复使用同一密码。管理后台必须开启双因素认证。

## 数据分级

公司数据分为公开、内部、秘密、机密四级。客户个人信息与财务数据属于机密级，导出需要数据负责人与安全负责人双重审批，且导出文件必须加密存放。

## 设备与网络

办公电脑必须安装公司统一的安全客户端，离开工位需锁屏。禁止将公司数据存储在未授权的个人网盘。访客网络与办公网络物理隔离。

## 离职与交接

员工离职当天由 IT 回收全部账号权限，直属上级负责确认工作资料的完整交接，涉及机密数据的岗位需签署竞业与保密协议后办理手续。
