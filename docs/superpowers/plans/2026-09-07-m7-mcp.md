# M7 实施计划：MCP 服务器（外部 Agent 连接知识库）

来源（Spec，权威）：docs/04-MCP服务设计.md v1.1（已确认，含 combine_lifespans 决策）· 分支：m7-mcp · 2026-09-07

## 全局约束

- 新增依赖仅 `fastmcp`（锁定版本；只使用 FastMCP 实例/工具注册/http_app/combine_lifespans 四个稳定面）。
- MCP 端点必须 Bearer 认证（无/坏/吊销 key 一律 401）；工具全部只读；工具/库中不得出现明文 key（日志与响应均不回显）。
- RAG/Web/设置等既有链路零行为变化；错误 detail 与注释中文；失败降级不 500。
- 基线 217 passed / 1 skipped 持续全绿；pnpm build 通过；每任务独立提交（中文信息）。
- 不要启动/关闭任何服务进程（真实联调由控制器做）；不要 push。

## T1 API Key 后端

- 模型 `ApiKey`：id PK, name String(100), key_prefix String(12), key_hash String(100), created_at, last_used_at 可空。Alembic 迁移（当前 head=b2c3d4e5f6a7，downgrade drop 表）。
- `services/api_keys_service.py`：generate（`zk-` + secrets.token_urlsafe(24)，bcrypt 哈希入库，返回明文一次性）、verify（bcrypt 比对）、touch（更新 last_used_at）。
- `api/keys.py`：POST /api/keys {name} → 201 {id, name, key_prefix, key}；GET /api/keys → 列表（无 hash）；DELETE /api/keys/{id} → 204。全部挂 require_auth；404 对不存在 id。
- 测试：创建返回明文且库里只有 hash；列表不带明文/hash；吊销后 verify 失败；404；require_auth 401。
- main.py 挂载 keys router。

## T2 MCP 服务器（核心）

- `uv add fastmcp`（锁定版本）。
- `services/mcp_server.py`：`FastMCP("zhifu")` 实例 + 五个工具（签名/语义按 Spec §三）：
  - list_workspaces / search(query, workspace_id?, top_k=5) / ask(question, workspace_id?) / list_documents(workspace_id, status?) / get_document(doc_id)
  - 复用服务层（retrieve/build_context/llm_complete/get_default_provider）；workspace_id 缺省时单工作区自动选中、多工作区报可读错误提示列出可选 id；LLM 未配置时 ask 返回明确工具错误文案（ToolError 或错误字符串，实现者按 fastmcp 惯例定，报告说明）。
  - 工具返回结构化 dict（fastmcp 自动转 content）。
- `api/mcp.py` 或 main.py 内：`mcp_http_app = mcp.http_app(path="/")`；ASGI 纯中间件（Starlette BaseHTTPMiddleware 或裸 ASGI，作用域仅 /mcp）校验 `Authorization: Bearer zk-…` → verify + touch（异步不阻塞返回路径，失败 401 JSON）；`app.mount("/mcp", mcp_http_app)`。
- **lifespan 接线（Spec 指定）**：`combine_lifespans(main_lifespan, mcp_http_app.lifespan)` 合并为 create_app 单一 lifespan——主应用 recover_interrupted 与 MCP 会话管理器同生命周期；fastmcp 版本 API 名如有出入按实际版本，报告说明。
- 测试：用 fastmcp 官方客户端（Client(transport) 指向 ASGI 应用，httpx ASGITransport 或 fastmcp 提供的 in-memory/transport 组合——以能走完整 Bearer 中间件为准）端到端：list_workspaces 返回种子工作区、search 命中 fake embedding 种子、无 key 401、坏 key 401、吊销后 401、多工作区缺省 workspace_id 的可读错误、ask 的 LLM 未配置降级。若 ASGI 层面客户端握手受 lifespan 限制，允许把「真实握手」留控制器联调并在报告注明，但 401/中间件逻辑必须有测试。
