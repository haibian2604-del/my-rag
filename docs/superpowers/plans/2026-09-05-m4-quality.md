## T1（A3）HNSW 向量索引

背景：`chunk_embeddings.embedding` 列无 typmod（多维度并存），pgvector 不能直接建 HNSW，需表达式部分索引 per dim。

- 新增 Alembic 迁移（down_revision=当前 head）：查询 `SELECT DISTINCT dim FROM chunk_embeddings`，对每个 dim 执行
  `CREATE INDEX IF NOT EXISTS ix_ce_hnsw_{dim} ON chunk_embeddings USING hnsw ((embedding::vector({dim})) vector_cosine_ops) WHERE dim = {dim}`；downgrade 循环 drop。dim 值是内部 int，f-string 内联安全。
- 新增 `ensure_vector_index(dim: int)`（放 app/core/db.py 或新 util，实现者定）：幂等建单 dim 索引；在 embedding_switch activate 流程调用（激活新模型时保证新 dim 有索引）。
- search.py 向量 SQL 适配（表达式索引要求查询侧用同一 cast）：查询前先 `SELECT dim FROM chunk_embeddings WHERE model_name=:model AND workspace_id=:ws_id LIMIT 1`（无行直接返回空列表，不查库），SQL 增加 `AND ce.dim = :dim`，距离表达式改为 `(ce.embedding::vector({dim}) <=> :qvec)`（dim int 内联），ORDER BY 同步 cast。
- 验收：全量测试绿；手测 `EXPLAIN` 一条向量查询确认命中 hnsw 索引（写入任务报告，不作硬断言）。

- 后端 chat.py `ask`：SSE 事件序列变为 `stage(retrieving)` → 检索 →（若配置了默认 rerank provider 则）`stage(reranking)` → `stage(generating)` → citations → delta* → done。事件格式沿用现有 JSON 行：`{"type":"stage","stage":"retrieving"}`。

## T3（A2）父子分块（本里程碑最大项）

数据模型：
- chunks 加列 `parent_id INTEGER REFERENCES chunks(id) ON DELETE CASCADE`（可空，索引）。语义：父块 parent_id NULL，仅存全文；子块 parent_id 指向父块，是唯一被嵌入/FTS/检索单元。
- **叶子原则**（兼容旧数据）：检索叶子 = parent_id 非空 OR 不存在指向自己的子块。旧文档未回填时父块自身即叶子，行为与现在完全一致。
- Alembic 迁移加列；downgrade drop。

chunking.py：
- 新增 `split_parents_and_children(blocks, parent_tokens=500, child_tokens=200, overlap_ratio=0.1)`：沿用现有结构感知聚合出父块；每个父块内部再切子块（同节内轻重叠、跨节不重叠）；子块继承 heading_path/page_no，token_count 单独算；父块内容过短（≤ child_tokens）时不切子块（父块自身即叶子）。
- 保留现有 `split_blocks` 行为签名不变或改为内部函数，实现者按最小扰动决定。

pipeline.py：
- ingest 写入父块行 + 子块行（fts 建在子块，父块 fts NULL）；嵌入仅对子块（无子块则嵌父块本身）。

search.py：
- 向量路与 FTS 路都加叶子过滤（`NOT EXISTS (SELECT 1 FROM chunks ch WHERE ch.parent_id = c.id)`）。
- 新增 `_aggregate_parents(hits)`：子块命中按父块分组去重，返回结构不变（chunk_id=父块 id、content=父块全文、heading_path/page_no 取父块、score=组内最高子块分、组内命中子块数可附带到新字段 child_hits 供前端展示）；rerank 在子块列表上做，聚合在后。
- 引用语义：citations 的 filename/heading_path/page_no 不变，snippet 内容变为父块级（前端 CitationCard 已可展开截断，无需大改）。

回填脚本：`python -m app.services.ingestion.backfill_parent_child`——遍历 status=ready 文档逐个重跑 run_ingestion_sync，失败记录继续，结尾打印汇总；README 补充说明（旧文档不回填也不影响检索，回填后享受父块上下文）。

测试：chunking 单测（父子映射、元数据继承、短父块即叶子、跨节不重叠）；search 单测（同父多子块去重、新旧混合文档叶子判定、score 取最高）；SSE/引用回归。

## T4（A1）PDF 解析轻量升级

parsing.py（PyMuPDF 路径）：
- 表格：`page.find_tables()` 抽取 → 转 Markdown 管道表行（`| a | b |`），插入到其在页面中的位置，并把表格区域从普通文本块中剔除避免重复；
- 版式排序：核对现有块序，必要时按 (y, x) 排序保证双栏可读（先看现状，最小改动）；
- 扫描件：PDF 总可提取字符 < 20 时抛错「疑似扫描件 PDF，暂不支持 OCR，请使用含文本层的 PDF」→ ingestion 落 failed + 该 error（不再产出空文档）。
